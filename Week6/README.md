# Week 6 – Spark Architecture and Data Processing using PySpark

## Objective

The objective of this assignment is to understand Spark Architecture, DataFrame operations, Spark transformations and actions, Parquet processing, filtering, schema modification, and Spark optimization techniques.

## Tools Used

- Python
- PySpark
- Jupyter Notebook
- VS Code
- Git & GitHub

## Dataset

A retail sales dataset containing customer orders and product information was used for implementing Spark DataFrame operations.

The dataset includes:

- Order Number
- Order Date
- Customer Name
- City
- State
- Customer Type
- Product Category
- Retail Price
- Order Quantity
- Order Total
- Shipping Cost
- Total


## Topics Covered

- Spark Architecture
- Driver, Cluster Manager and Executors
- Lazy Evaluation
- Spark DAG
- DataFrame Filtering
- Column Selection
- Column Renaming
- Data Type Casting
- Predicate Pushdown
- Transformations vs Actions
- Client Mode vs Cluster Mode
- Parquet Processing

## Practical Operations Performed

- Loaded CSV dataset using Spark.
- Selected required columns using DataFrame operations.
- Filtered records based on conditions.
- Renamed columns.
- Converted string columns to numeric data types.
- Created new calculated columns.
- Performed logical filtering using AND and OR operators.
- Explored Spark transformations and actions.
- Studied Parquet read/write syntax.
- Understood Spark architecture and execution flow.

## Key Learning Outcomes

- Learned Spark Architecture and execution workflow.
- Understood Driver, Cluster Manager and Executors.
- Implemented DataFrame transformations.
- Applied filtering and column selection.
- Performed schema modification and type casting.
- Created derived columns using Spark.
- Understood the importance of Lazy Evaluation.
- Learned the advantages of Parquet format.
- Differentiated between Client Mode and Cluster Mode.

## Conclusion

This assignment strengthened the understanding of Spark Architecture and PySpark DataFrame operations. It provided hands-on experience in filtering, transforming, modifying schemas, and understanding Spark's execution model and optimization techniques.
